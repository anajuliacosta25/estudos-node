# Minha Calculadora

O projeto foi desenvolvido a fim de aprimorar os conhecimentos básicos em HTML, CSS e, principalmente, JavaScript puro.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## Funcionalidades
A calculadora conta com a realização de cálculos matemáticos básicos, sendo eles:
- Soma;
- Subtração;
- Multiplicação;
- Divisão;
- Porcentagem;
- Cálculos utilizando decimais.

Também possui tratamentos para cálculos com divisão por zero (0), conversão de strings para números, números para strings e números com vírgula (,).

## Como executar
Para executar a calculadora, baixe o projeto disponível em meu perfil do GitHub e abra o arquivo HTML em um navegador de sua preferência.

Após o projeto estar aberto em seu navegador, realize os cálculos necessários de acordo com sua necessidade!

## O que aprendi
Este projeto foi muito importante para o início do meu aprendizado, utilizando as tecnologias mencionadas, mas, principalmente, para praticar a programação em JavaScript de forma prática com algo que, mesmo simples, é funcional para o usuário. 

Nele, pude desenvolver minhas habilidades em:

- Manipulação do DOM;
- Declaração de variáveis;
- Eventos;
- Funções;
- Condicionais;
- CSS;
- Entre outros conceitos utilizados no código da aplicação.

Muito mais do que apenas desenvolver uma calculadora, pude entender o que escrevi e explicar o que foi realizado na programação de todo o projeto, o que para mim, é muito gratificante diante da vontade e determinação em aprender uma nova linguagem.
